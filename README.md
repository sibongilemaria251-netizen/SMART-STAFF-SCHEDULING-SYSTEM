# Smart Staff Scheduling & Event Management System

## ICT300 Group Project

**Team Name:** Visionary Coders


## 📌 Project Overview

The Smart Staff Scheduling & Event Management System is a web-based solution designed to improve staff scheduling and event coordination for catering businesses.

The system helps managers assign the right staff members to the right events based on skills, certifications, and availability while reducing scheduling conflicts and improving communication.


## 🎯 Problem Statement

Many catering businesses still manage staff manually, leading to:

* Double booking of staff
* Incorrect role assignments
* Poor communication between staff and management
* Lack of visibility into staff skills and certifications
* Difficulty identifying staffing shortages


## 💡 Proposed Solution

Our system provides:

* Automated staff scheduling
* Skill-based staff assignment
* Certification prioritization
* Skill gap detection
* Hiring suggestions
* QR check-in functionality
* Staff and manager dashboards


## 🖥️ System Features

### Staff Features

* View assigned shifts
* QR check-in
* View personal skills and certifications

### Manager Features

* View all staff members
* Filter staff by skills
* Detect skill shortages
* Receive hiring suggestions
* Monitor event staffing requirements

### Administrator Features

* Manage project repository
* Organize system structure
* Manage documentation
* Prepare deployment configuration
